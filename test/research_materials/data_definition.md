# 데이터 정의: 무엇을, 어느 기간·간격으로, 어떤 결측과 함께 쓰는가

연구 전체가 공유하는 데이터 개요 문서다(번호 없음). 변수 단위의 정의와 파생 공식은
`test/results/DATA_DICTIONARY.md`가 맡고, 이 문서는 그보다 앞 단계인 데이터 자체의
성격(기간, 간격, 결측과 그 원인, 비정상성, 분할)을 적는다. 수치는 2026-10-05에 `upbit_krw_candle`
에서 직접 계산한 값이며, 대표 종목은 BTC(유동성 높음)와 DOGE(호가 단위가 거친 알트)다.

## 1. 데이터 정의

| 항목 | 내용 |

| 간격 | 15분봉(OHLC, 거래량, 거래대금) |
| 기간 | 2023-07-19 ~ 2026-07-19(약 3년), 종목당 약 10만 5천 봉 |
| 시간대 | KST로 추정. 근거: 2025-01-01 정기점검 공지(02:00~)와 데이터의 공백 시작 시각(02:00 직전)이 일치 |
| 전체 종목 | 269종목, 이 연구는 그중 20종목(`study_universe()`) |

AQT·AERGO는 7월 이후 업비트 KRW 마켓에서 상장폐지되어 API가 빈 응답을 준다. 생존 편향을 피하려고 종목군에 남기고 2026-07-18까지만 평가한다 |

## 2. 결측은 세 종류이고 원인이 서로 다르다

| 종류 | 규모 | 원인 | 근거 | 처리 방침 |
| :--- | :--- | :--- | :--- | :--- |
| 거래소 점검 공백 | 종목당 15건(전 종목 같은 시점), 한 번에 약 0.75~7시간 | 서버 점검·정기 실사로 전 마켓 거래 중단. 분기 초와 연초에 집중 | 2025-01-01 공백은 업비트 공지로 확인("서버 점검 02:00~08:00, 모든 마켓 거래 일시 중단"). 나머지 14건은 공지와 개별 대조하지 않았고 날짜 패턴(분기 초·연초)만 근거다 | 보간하지 않고 공백을 가로지르는 수익률·변동성 창을 예외 처리로 제외 |
| 무체결 봉 누락 | 유동성 낮은 종목에서 최대 약 7.8%(MOC 8,104봉, BOUNTY 7,877봉). BTC·ETH는 약 0.25% | 업비트는 해당 15분에 체결이 없으면 캔들을 만들지 않는다 | 업비트 API 문서: "캔들은 해당 시간대에 체결이 발생한 경우에만 생성된다" | 시간 격자로 복원하고 종가를 이어받아 수익률 0(무거래 표식)으로 둔다. 현재 24·25번은 행을 그대로 이어붙여서 영향 평가가 필요하다 |
| 영수익률 | DOGE는 15분 수익률이 0인 봉이 23%. 그중 거래량 0인 봉은 한 건도 없다 | 호가 단위 이산성. 값이 싼 종목일수록 한 칸도 못 움직이는 봉이 많다 | 거래량 100% 존재, 24시간 고르게 분포. 호가비율과의 종목 간 상관은 0.26이라 이것만이 원인이라고 단정하지는 않는다 | 학습 표본에서 제외(Sucarrat & Escribano 2018). 시퀀스 모델 입력은 직전값 유지 + 손실 마스크. 26c번부터 로그 타깃 모델은 정지 확률 π를 따로 예측하는 두 부분 모형(Duan 외 1983)으로 RV=0 시점을 다룬다 |

시퀀스 모델 입력의 결측 대체는 20종목에서 일부러 가린 값을 복원해 비교했다(로그RV 표준편차 단위
오차): 전역평균 1.01, EWMA 0.70~0.79, 직전값 유지 0.62, 칼만 필터(인과 평활) 0.62. 인과적인
평활의 최적해가 직전값 유지로 수렴해서 이를 쓴다.

## 3. 비정상성은 이렇게 나타난다

| 대상 | 판정 | 수치(BTC 기준) |
| :--- | :--- | :--- |
| 로그가격 | 비정상 | ADF p=0.89, KPSS p=0.01. 3,800만 원에서 1억 8천만 원까지 올랐다가 9,400만 원으로 복귀 |
| 로그수익률 | 평균은 안정, 꼬리가 극단 | 초과첨도 107(주기 제거 후 30), 1차 자기상관 -0.04(DOGE -0.17, 호가 튐 효과) |
| 수익률의 크기 | 군집이 뚜렷함 | \|수익률\| 자기상관 1봉 0.32, ARCH 검정 p≈0 |
| 타깃(로그 실현변동성) | 평균 회귀하지만 기억이 길다 | 자기상관 1봉 0.87, 1시간 0.50, 1일 0.30, 1주 0.16. 편자기상관은 1봉 0.86 뒤 0 근처. ADF는 정상, KPSS는 비정상으로 갈려 약한 비정상으로 본다 |

한 줄 해석: 가격은 방향 없이 떠돌고(수익률은 거의 예측 불가), 변동성만 며칠 단위로 이어지는
기억을 갖는다. 그래서 이 연구는 수익률이 아니라 변동성을 예측 대상으로 삼는다. DOGE는 같은 수치가
자기상관 1봉 0.90, 1일 0.47, 1주 0.33으로 기억이 더 길다.

## 4. 변동성의 크기와 학습/평가 구간의 차이

| 항목 | BTC | DOGE |
| :--- | :--- | :--- |
| 1시간 변동성 중앙값 | 0.29% | 0.78% |
| 상위 5% / 99.9% / 최대 | 0.85% / 2.7% / 9.5% | 2.0% / 6.2% / 21.2% |
| 최대는 중앙값의 몇 배 | 33배 | 27배 |
| 가장 높은 5% 시간이 차지하는 변동 | 42% | 36% |
| 월별 중앙값 범위 | 0.17~0.48%(2.8배) | 0.27~1.37%(5.1배) |
| 학습 → 평가 중앙값 | 0.29% → 0.28% | 0.68% → 0.96%(+41%) |

BTC는 학습과 평가의 수준이 거의 같고, DOGE는 평가 구간에서 변동성이 크게 올라 있다. 종목에 따라
"학습 때 못 본 수준을 예측해야 하는" 정도가 다르다는 뜻이다.

## 5. 3년 데이터를 쓴 이유: 현재 기록된 근거가 없다

수집 기록(history.md 2026-05-28)에 "3년 15분봉"이라고만 있고 선택 근거는 적혀 있지 않다. 업비트 API
문서에도 과거 조회 한도는 명시돼 있지 않다. 근거가 될 수 있는 후보는 아래와 같지만 모두 검증 전이다.
- 표본 수: 종목당 약 10만 봉으로 딥러닝과 GARCH 추정에 충분하다.
- 시장 국면: 이 기간에 BTC가 최저 3,417만 원에서 최고 1억 7,981만 원까지 움직여 상승과 하락 국면을 모두 포함한다.
- 최근성: 거래소 구조와 상장 종목이 계속 바뀌므로 너무 오래된 구간은 현재와 다를 수 있다.
근거를 실험으로 만들려면 학습 창을 1년, 2년, 3년으로 바꿔 평가 구간 성능이 어떻게 변하는지 보는
민감도 분석이 필요하다. 아직 하지 않았다.
