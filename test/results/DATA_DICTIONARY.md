# 데이터 사전 (DATA DICTIONARY) — 살아있는 문서

모든 보고서는 이 문서를 참조한다. RAW에서 시작해 EDA·전처리로 파생변수가 생길 때마다
여기에 누적 등록한다. 각 변수는 **정의/공식 · 무엇으로부터 · 독립(X)/종속(y) · 근거 유형 ·
추가 시점**을 함께 적는다. 근거 유형: `관례`(방법론 표준) / `가정`(모델 가정 충족) /
`EDA`(데이터에서 확인) / `방법`(구현상 필요).

## 3. 타깃(종속변수) — 확정(26번부터)

- **RV_H**: 다음 H분(15·30·60·240·720분) 실현변동성. 평가는 정시 비겹침 시각, 손실은 QLIKE(Patton 2011), 성적은 naive와 함께 본다(2.9d).
- 로그 타깃 모델은 ln(act_d)를 학습해 주기·보정·정지 확률로 원 척도 RV_H 예측을 만든다. GARCH 계열은 d의 조건부 분산을 다단계로 예측해 같은 RV_H로 바꾼다.
- 근거 유형: EDA(변동성 군집·조건부 이분산, 21번) + 관례(실현변동성).
