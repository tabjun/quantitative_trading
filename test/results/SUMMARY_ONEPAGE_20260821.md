## 2. 핵심 발견 — 계속 재확인됐고 흔들리지 않았다

> **15분봉에서 방향(오를지/내릴지)은 예측 불가하고, 변동의 크기(변동성)는 예측 가능하다.**

- 방향 자기상관 ≈ −0.05~0.09, 방향 정확도 0.48~0.54(동전 던지기)
- 크기(\|수익률\|) 자기상관 0.36 → 느리게 감소, GARCH로 0.46까지 포착
- 전종목 20~30개, 여러 실험, 여러 재실행에서 **예외 없이 재현**됐다(가장 견고한 근거)

이 결론은 8/13 이후의 모든 재검증(축 교정, 다중시드, 20종목 확인)을 통과했다. **바뀐 적이 없다.**

## 4. B(변동성) 갈래 내부에서 확인한 것 — 단, 상위 결정 전이라 잠정적

A/B/C가 정해지지 않은 상태에서 B의 세부(어떤 모델)까지 파고든 것은 **순서가 앞서갔다.**
그래도 나온 결과는 후속에 쓸 수 있으므로 요지만 남긴다.

- 주기 성분 제거는 6모델×3horizon **18개 조합 전부**에서 이득 → B를 하게 되면 항상 먼저 제거
- target 15분~4시간이면 GARCH-t가 20종목 중 55~80%에서 최다
- **target 16시간은 GARCH-t와 HAR-RV가 정확히 동률(20종목 중 7개씩)** — 단일 모델로 확정 못 함
- 269종목 표본은 생존편의가 구조적으로 있다(수집 후 1개월에 2종목 폐지 확인). 크기는 못 잰다
